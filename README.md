# GumAgent Privacy Policy

**Last updated: September 25, 2026**

GumAgent is an internal automation tool used to promote and analyze digital products sold through Gumroad.

## Information GumAgent accesses

When connected to Pinterest, GumAgent may access information associated with the Pinterest business account that authorized the application, including:

- Pinterest profile information;
- boards;
- Pins created or managed by the account;
- Pin and board analytics made available through the Pinterest API.

GumAgent does not intentionally access private Pinterest data belonging to unrelated users.

## How information is used

Pinterest data is used only to:

- create and manage organic Pins for GumAgent products;
- link Pins to relevant Gumroad product pages;
- measure traffic and content performance;
- analyze campaign performance;
- improve future marketing content.

GumAgent does not sell Pinterest user data.

## Data sharing

Data obtained through the Pinterest API is not sold or rented to third parties.

Data may be processed by infrastructure and service providers required to operate GumAgent, subject to their respective privacy and security practices.

## Data retention

GumAgent stores only information reasonably necessary for campaign tracking, attribution, analytics, and application operation.

Authentication credentials and API tokens are stored separately from public source code and are not intentionally exposed publicly.
